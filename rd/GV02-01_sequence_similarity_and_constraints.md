# GV02-01 蓝藻 GvpA：序列相似度、功能等价性与约束评价

> 用途：解释项目动机中的关键表述，并将其转化为 GV02-01 可执行的生成与评价原则。  
> 适用范围：蓝藻 GvpA 序列生成，不替代实验验证或正式生物学注释。

## 1. 先给结论

你提出的理解**基本正确，但需要加一个重要限定**：

> 两条蛋白质序列即使整体相似度很低，也可能因为保留了相同的折叠方式、关键结构位点、表面物理化学性质或相互作用方式，而具有相近的功能；反过来，序列只发生少数变化，也可能因为改变了关键位点、界面或稳定性，导致结构和功能明显变化。

因此：

- **序列相似度不是功能相似度的同义词**；
- 序列相似度适合衡量同源关系、数据泄漏和“是否过度复制已知序列”；
- 它不适合单独作为生成质量或功能保持的最终判据；
- 生成任务的核心确实不是“能否生成一条合法字符串”，而是“生成结果在多大程度上满足目标蛋白已知的多层约束”。

但“完全不同的序列仍然功能相同”不能被理解为“序列可以随意变化”。蛋白质通常是在**关键约束被保留**的前提下允许较大范围变化。对 GvpA 来说，这些约束包括家族身份、核心折叠、β-sheet 壳体相关的几何和物理化学性质，以及与其他 Gvp 蛋白组装所需的界面特征。

## 2. 为什么序列相似度不等于功能相似度

蛋白质可以从不同层次进行比较：

| 层次 | 关注的问题 | 与序列 identity 的关系 |
| --- | --- | --- |
| 序列层 | 氨基酸是否相同 | identity 高通常表示更接近，但不直接证明功能相同 |
| 结构层 | 是否保持相似三维折叠 | 结构约束可能比逐位相同更重要 |
| 物理化学层 | 疏水性、电荷、柔性、体积、界面性质是否相近 | 不同氨基酸可能具有相近的性质 |
| 功能层 | 是否能完成同一分子功能 | 由结构、位点、动态和相互作用共同决定 |
| 系统层 | 是否能表达、组装并产生目标表型 | 还依赖其他蛋白、基因线路和实验条件 |

### 2.1 保守的是“性质”和“模式”，不一定是每个字母

例如，某个位置需要疏水残基来形成内部核心时，I、L、V、M 等替换可能仍然满足主要物理需求。某个表面位置需要带正电时，K 与 R 可能具有一定程度的可替代性。这类替换会降低逐位 identity，却可能基本保留局部结构或界面性质。

这也是为什么多序列比对中的保守性不应只看“最常见的具体氨基酸”，还应看：

- 该位置的氨基酸类别是否保守，例如疏水、带电、极性；
- 位点在结构中处于核心、表面、转角还是蛋白互作界面；
- 相邻位点是否共同形成一个保守的局部模式；
- 整体长度、二级结构倾向和表面性质是否仍处于合理范围。

### 2.2 少量突变为什么可能造成很大影响

“小变动导致大变化”也不是每个位点都成立。风险通常集中在：

- 疏水核心或 β-sheet 堆积相关位置；
- 蛋白-蛋白组装界面；
- 转角、边缘和决定局部几何的位点；
- 改变电荷、体积或柔性的关键位置；
- 多个位点之间存在协同作用的区域。

所以，蛋白质序列设计不是简单地最大化新颖性，而是在不同位置施加不同强度的约束：关键位点更严格，允许替换的位点更宽松。

## 3. 这句话放到 GvpA 项目中是什么意思

GvpA 是气囊的主壳体蛋白。项目真正要生成的不是“看起来像训练集的字符串”，而是满足以下条件的候选：

1. **身份约束**：属于目标 GvpA-like 家族，而不是只因为宽泛 profile 命中就把 GvpJ/GvpM/GvpK 等同源蛋白混入；
2. **结构约束**：能够合理支持 GvpA 的壳体折叠和 β-sheet 相关结构特征；
3. **物理化学约束**：内部/外部表面相关的疏水性、亲水性、带电性和整体组成不能明显失真；
4. **组装约束**：至少不能明显破坏与气囊壳体形成相关的界面和局部模式；
5. **分布约束**：长度、保守位点、氨基酸组成和 PLM 表示应与真实蓝藻 GvpA 的合理区域相容；
6. **新颖性约束**：不能只是训练集中的 exact copy 或近乎复制品；
7. **集合多样性约束**：候选之间不能全部塌缩到同一条模式。

因此，项目中的“新颖序列”应被定义为：

> 在不破坏 GvpA 家族和结构相关约束的前提下，与已知序列存在有意义差异的候选。

而不是：

> 与所有已知序列尽可能不相似的候选。

后一个定义会鼓励模型生成随机、离群、甚至不再属于 GvpA 的序列。

## 4. 为什么本项目仍然需要相似度指标

相似度不是错误指标，错误的是把它当成唯一指标。它在本项目中至少有四个明确用途：

### 4.1 防止数据泄漏

如果训练集和测试集存在大量近重复序列，模型的高分可能只是记忆相似序列，而不是学到了 GvpA 的规律。因此需要基于 similarity cluster 做划分，而不能只随机划分。

当前 `dataset_v1` 已完成这项控制：165 条序列，train/valid/test 为 139/13/13，跨集合达到 95% identity 且覆盖不低于 80% 的序列对为 0。

### 4.2 检测生成模型是否复制训练集

生成序列与训练集的 nearest-neighbor identity 很高，说明它可能只是记忆化；这对生成任务是风险信号。

### 4.3 衡量新颖性

可以把与训练集最近邻的 identity 作为新颖性的一部分，但必须同时报告 query coverage 和 target coverage。只看 identity 可能被短序列、局部比对或长度差异误导。

### 4.4 描述候选集内部是否趋同

候选两两之间的距离可以用于估计多样性。但是 pairwise distance 高也可能只是生成了大量不合理序列，因此必须和 family/profile、长度、组成及 embedding 结果联合解释。

## 5. 建议采用“分层约束 + 多目标评价”

不要把所有指标过早压缩成一个总分。建议按以下顺序评价。

### 5.1 第一层：硬约束过滤

不满足以下条件的序列直接标记为 invalid，不进入后续“优质候选”比较：

- 只含标准氨基酸字符；
- 长度位于训练数据支持的合理范围；
- 没有空序列、明显截断或异常终止；
- 通过正式的 GvpA family/profile 检查；
- 不与训练集 exact copy；
- 必要时满足最小覆盖率和 profile score 要求。

这里的 family 判定应使用已确认的工具、数据库版本、阈值和配置。当前仓库的生物学审计指出，课程材料中的 `PF01132` 与当前 GvpA 注释不一致；现行数据流程使用官方 `PF00741 / Gas_vesicle`，并结合本地高可信 GvpA profile、注释和分类学证据。`PF00741` 本身较宽泛，不能单独证明 GvpA 身份。

### 5.2 第二层：软约束和结构代理指标

对通过硬约束的序列计算连续分数或风险指标：

- MSA 保守位点的一致性；
- 核心列 occupancy、entropy 和 gap rate；
- 氨基酸组成与真实训练集的距离；
- 疏水性、电荷和极性分布；
- 局部 motif 或保守模式是否被破坏；
- 预测二级结构或结构模型中的 β-sheet 相关特征；
- 与真实序列的 ESM-2 embedding 分布距离。

这些指标是“结构/功能可信度的计算代理”，不是实验功能的直接证明。

### 5.3 第三层：新颖性和多样性

建议分别报告：

- `exact_copy_rate`；
- `nearest_train_identity` 的均值、分位数和最大值；
- 在多个 identity 阈值下的 novelty rate；
- nearest-neighbor 的 query/target coverage；
- 候选集 unique ratio；
- 候选内部平均 pairwise distance；
- 最大重复簇占比。

不要只报告“identity < 95% 的比例”。95% 可以作为项目操作阈值，但不是生物学上普适的“功能不同/相同”分界线。

### 5.4 第四层：功能的间接评价

如果接入 GV01-02/GV01-03 的功能预测或关键位点模型，可以作为生成结果的额外证据：

- 预测为 GvpA-like 的比例；
- 功能预测置信度分布；
- 关键位点或关键区域的保留情况；
- 生成序列与真实序列在预测功能空间中的分布差异。

这仍然是模型间接验证，不等价于湿实验。最终结论应使用“计算预测支持”或“值得进一步验证”，不能写成“已经证明具有真实气囊功能”。

## 6. 如何理解三个目标之间的冲突

三个目标不是同一个方向：

| 目标 | 过低时的问题 | 过高时的问题 |
| --- | --- | --- |
| 约束满足度 | 生成不再像 GvpA，可能无法折叠或组装 | 复制训练集，创新不足 |
| 新颖性 | 候选没有设计价值 | 可能破坏保守结构和家族身份 |
| 多样性 | 候选集模式塌缩 | 可能充满离群或无效序列 |

因此更合理的结果不是“找到一个同时把三个指标都推到极致的模型”，而是寻找 Pareto 前沿：在约束满足度已经过关的候选中，再比较新颖性和多样性。

推荐报告以下几类候选，而不是只选一个冠军模型：

1. **保守型候选**：约束高、与已知序列较近，适合作为可靠性对照；
2. **平衡型候选**：约束通过且具有中等新颖性和较好集合多样性；
3. **探索型候选**：新颖性高但需要结构预测、功能预测或实验优先验证；
4. **离群/失败候选**：新颖性高但 family、长度、组成或 embedding 明显异常，用于分析模型失败模式。

## 7. 对 RQ1--RQ3 的具体解释

### RQ1：哪种生成策略更善于保持结构约束？

不能只用 sequence identity 回答。应比较各方法的：

- family/profile 通过率；
- 长度和合法字符通过率；
- MSA/保守位点一致性；
- 结构代理指标；
- 在相同生成数量和随机种子设置下的有效候选率。

一个模型可能 identity 很低，但 profile 和结构代理指标很好；也可能 identity 很高，却只是复制训练集。前者可能是有价值的新颖候选，后者只能说明模型记忆能力较强。

### RQ2：约束、新颖性、多样性是否存在甜点？

应绘制三目标散点图、Pareto 前沿和分层过滤后的结果。重点不是证明三个目标“完全没有冲突”，而是回答：

- 在 family/profile 通过的候选中，新颖性提高到什么程度后有效率开始下降；
- 不同模型的有效候选区域是否不同；
- 生成温度、VAE 的 beta 或 latent scale 如何改变这三个目标；
- 是否存在一段参数区间，使约束通过率没有明显下降，同时新颖性和多样性得到提升。

### RQ3：PLM embedding 能说明什么？

embedding 可以帮助判断生成序列是否落在真实 GvpA 分布附近，以及是否出现明显分布外样本，但它不能单独证明功能。

建议同时观察：

- 真实序列与生成序列的局部邻域重叠；
- 生成样本是否只挤在真实分布中心；
- 是否覆盖真实数据的多个簇或区域；
- 是否存在远离真实分布、但仍通过表面 profile 的异常样本；
- MMD/核距离变化是否与 family 通过率、新颖性和多样性一致。

t-SNE 主要用于可视化，不宜把二维图上的距离当成严格的生物学距离。MMD 或核距离在本项目中属于探索性分布指标，应明确标注为辅助证据。

## 8. 对当前项目实现的直接建议

结合仓库现状，建议按以下优先级推进：

1. 先把 HMMER/profile 扫描接入 evaluator，消除当前 `family_profile_status = not_run` 的空缺；
2. 保持 `dataset_v1`、固定拆分和随机种子不变，所有模型输出统一进入同一个 evaluator；
3. 对 AA-frequency、k-mer、LSTM、VAE 至少报告合法性、长度、exact copy、nearest-train identity/coverage、novelty、unique ratio、pairwise diversity、组成距离和 profile 通过率；
4. 对 LSTM 的 temperature、VAE 的 beta/latent scale 做参数扫描，而不是只比较单个 checkpoint；
5. 再接入 ESM-2 embedding、t-SNE/UMAP 和 MMD，作为分布分析，不替代 profile 和结构约束；
6. 从 profile 通过的候选中按 Pareto 前沿挑选样本，分别输出保守型、平衡型和探索型候选；
7. 对最终候选做人工审查，并在报告中明确计算边界。

当前冻结数据集为 165 条蓝藻 GvpA，长度范围 59--91 aa，train/valid/test 为 139/13/13。由于有效样本量仍然较小，模型差异应通过多个随机种子、参数区间和置信区间解释，不能把一次生成结果当作普遍规律。

## 9. 推荐在报告中使用的表述

可以这样写：

> 序列相似度是评估同源关系、数据泄漏和生成新颖性的有用指标，但不是功能相似度的充分条件。蛋白质功能通常由序列、结构、物理化学性质和分子相互作用共同决定，因此具有较低序列相似度的蛋白仍可能保留相近功能，而关键位点的小幅变化也可能造成显著功能影响。对于蓝藻 GvpA，本项目将 family/profile、长度、保守模式、组成和结构代理指标作为约束满足度证据，并将序列相似度用于新颖性与防记忆化评价，再结合候选集多样性和 PLM 嵌入分布进行多维度联合分析。

不建议这样写：

> 只要与已知 GvpA 序列相似度低，就说明生成了新的、功能相同的 GvpA。

这句话同时混淆了新颖性、家族身份和真实功能，证据强度不够。
